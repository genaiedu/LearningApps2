für EB Garamond, abgerufen am 19. Oktober 2026. Keine lokalen Instanzen des
Variable Fonts. Quelle des Pakets:

Alle vier Dateien wurden auf fvar (nicht vorhanden), erlaubte Einbettung
(OS/2.fsType = 0) und kern, liga, smcp, c2sc, onum, lnum, pnum, tnum geprüft.
Die Wordbeispiele betten diese vier Schnitte und die vier entsprechenden
statischen Fira-Sans-Schnitte vollständig ein; die Lizenztexte sind zusätzlich
in jedem Dokumentpaket enthalten.
