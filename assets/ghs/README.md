# GHS-Piktogramme für die Kinetik-Unterlagen

Unveränderte SVGs von Wikimedia Commons, nach den GHS-Symbolen der UNECE.
Abruf: 7. Oktober 2026. Die jeweiligen Commons-Dateiseiten weisen Public domain aus.
Quelle und Dateihistorie: https://commons.wikimedia.org/wiki/Category:GHS_pictograms_(Vector_drawings)

| Datei | Code | Bedeutung |
| --- | --- | --- |
| GHS-pictogram-rondflam.svg | GHS03 | Brandfördernd |
| GHS-pictogram-acid.svg | GHS05 | Ätzwirkung / Metallkorrosion |
| GHS-pictogram-skull.svg | GHS06 | Akute Toxizität |
| GHS-pictogram-exclam.svg | GHS07 | Unter anderem Augenreizung |
| GHS-pictogram-silhouette.svg | GHS08 | Gesundheitsgefahr |
| GHS-pictogram-pollu.svg | GHS09 | Gewässergefährdend |

Dateiseiten: `https://commons.wikimedia.org/wiki/File:` plus Dateiname.
Die Kennzeichnung muss stets zur tatsächlichen Stoffform und Konzentration passen.
Insbesondere hat die ausgewählte Permanganatlösung 0,01 mol/l laut AnalytiChem-SDB
vom 28.08.2025 H412, aber kein GHS09-Piktogramm. Die Feststoffsymbole dürfen nicht
auf diese Lösung übertragen werden.
