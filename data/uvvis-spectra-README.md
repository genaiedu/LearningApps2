# UV/Vis laboratory: numerical source provenance

`uvvis-spectra.json` contains 77 substance records (73 distinct CAS identities), including 72 measured pH
curves across five substances. It is generated by
`scripts/import-uvvis-data.py`. Run with Python and openpyxl from the repository
root. The importer caches read-only source responses in ignored `tmp/` and
records retrieval date, original URL and SHA-256 for traceability.

## Sources and permissions

- **71 PhotochemCAD 3 records:** published numerical absorption measurements,
  with the authors' literature scaling to molar absorption coefficients.
  https://www.photochemcad.com/ . The importer preserves individual source
  credits, instrument, solvent, reference peak and data-file URL. This does
  not assert that PhotochemCAD's entire database, images or software have a
  Creative Commons licence; no database illustrations or code are copied.
- **Five pH series:** Satoru Goto (2026),
  https://doi.org/10.17632/jp2j9hz6v9.1 , CC BY 4.0. Only measured wavelength
  and absorbance columns from the explicitly selected workbook sheets are
  imported; derived fits and calculations are excluded. Each curve contains
  551 original points from 250 to 800 nm. Concentration is not established by
  the selected table headers, so the app permits relative dilution only.
- **Indigo carmine:** Zanoni et al. (2010),
  https://doi.org/10.1590/S1984-82502010000400014 , Figure 2, trace A. SciELO
  specifies CC BY-NC 4.0. This noncommercial educational adaptation digitizes
  the visible curve at 24 manually identified pixel positions, using the
  figure's axis calibration. The approximate uncertainty (about ±0.005 A)
  and the transformation are disclosed. It is not a new measurement, a
  fitted Gaussian curve, or a quantitatively validated calibration dataset.
- **Structures:** PubChem identifiers and connectivity SMILES. RDKit's local
  BSD-licensed minimal module draws structures; its licence is in the shared
  LearningApps assets. Structures identify compounds, not every pH-specific
  protonation state or the conformer used in the source experiment.

## Separation of data and instrument model

Raw imported values are retained, including small negative instrumental
baselines. The simulator uses linear interpolation, prohibits extrapolation,
and clamps negative absorption to zero for its ideal transmission model.
Spectral bandwidth averages transmission, not absorbance. Solvent/cuvette
cutoffs, optional stray light and noise are explicitly simplified teaching
models, not vendor specifications. Dilution obeys Lambert–Beer only under
its stated assumptions (unchanged chemical species, dilute homogeneous
solution). Source absorbance curves use a relative factor, never an invented
molar concentration. Quantification is restricted to epsilon records.

The instrument exterior is an original, perspective-consistent Three.js model,
visually informed by manufacturer photos of the Shimadzu UV-1900i Plus. It is
not a manufacturer photograph or a dimensionally accurate reproduction.
The optical plan is adapted from TobiasFar's `Aufbau UVVIS.gif` (2004),
https://commons.wikimedia.org/wiki/File:Aufbau_UVVIS.gif , CC BY-SA 3.0.
The adapted diagram is also CC BY-SA 3.0. Changes: SVG redrawing, controllable
time multiplexing, sample attenuation, digital ratio measurement instead of
the historical comb-aperture null-balancing method. The unmodified original
GIF is additionally embedded directly from Wikimedia after user consent.
No external image or Wikipedia request occurs before consent; numerical
data, the local optical plan, Three.js and structures load locally.

## Verification

- `node tests/uvvis-core.test.cjs`: source metadata, original pH values,
  dimensions, cutoffs, optical model, regression, comparisons and question pool.
- `node tests/uvvis-browser.cjs` with Playwright: molecule validity, device
  workflow, scan, dilution/calibration, invalidation, fullscreen, quiz persistence,
  responsive layout and absence of unsolicited external requests.
